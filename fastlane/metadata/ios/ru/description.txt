Libellus Potionis — это бесплатный трекер потребления алкоголя с открытым исходным кодом, без рекламы и с приоритетом приватности, который помогает отслеживать, дозировать и контролировать привычки потребления полностью офлайн. Он не требует навязчивых разрешений устройства — ни камеры, ни микрофона, ни геолокации — и работает совершенно без сетевого подключения.

ОСНОВНЫЕ ВОЗМОЖНОСТИ

• Запись: Задавайте собственные напитки или выбирайте из распространённых во всём мире шаблонов. Записывайте напитки сразу или задним числом с коррекцией времени.
• Несколько лимитов одновременно: Задайте три лимита параллельно — дневной лимит (граммы чистого алкоголя), скользящий недельный лимит за 7 дней (граммы) и максимальное число дней употребления в неделю. У каждого свой индикатор прогресса.
• Оценка концентрации алкоголя в крови (BAC): Введите массу тела, чтобы получить текущую оценку по формуле Видмарка.
• Отчёты для консультаций: Создайте двухстраничный PDF-отчёт о своём потреблении для консультаций и приёмов.
• Переносимость данных: Экспортируйте свои данные в файл CSV для внешней обработки (например, в LibreOffice Calc) или создавайте резервные копии JSON для переноса данных между устройствами.
• Настройки: Настройте время «начала дня», чтобы напитки поздней ночью засчитывались в предыдущий вечер, и задайте дату начала оценки, когда захотите начать заново, например в новогоднюю ночь.

Внутри приложения доступно руководство пользователя.

КОНФИДЕНЦИАЛЬНОСТЬ И БЕЗОПАСНОСТЬ

Приложение сохраняет только то, что вы вводите сами. В нём вообще нет сетевого кода, поэтому оно не способно обращаться к сети, и ваши данные не покидают устройство сами по себе. Ваши данные остаются в приватном хранилище приложения, защищённые в покое с помощью iOS Data Protection (аппаратно поддерживаемое шифрование файлов) и песочницей приложения. Необязательная блокировка Face ID или Touch ID защищает от несанкционированного физического доступа. Нет ни слежки, ни аналитики, ни облачной синхронизации.

СОВМЕСТИМОСТЬ

Приложение работает на iOS 17 и новее, а также доступно для Android 11 (API 30) и новее.
