Libellus Potionis는 프라이버시를 최우선으로 하는 오픈 소스, 무료, 광고 없는 음주 기록 앱으로, 음주 습관을 파악하고 조절하고 관리하도록 완전히 오프라인에서 돕습니다. 카메라, 마이크, 위치 같은 침해적인 기기 권한을 전혀 요구하지 않으며, 네트워크 연결 없이 작동합니다.

주요 기능

• 기록: 나만의 음료를 정의하거나 국제적으로 흔한 프리셋에서 선택할 수 있습니다. 음료를 즉시 또는 시간 보정과 함께 사후에 기록할 수 있습니다.
• 여러 한도를 동시에: 세 가지 한도를 병행해 설정합니다 — 일일 한도(순수 알코올 그램), 7일 이동 주간 한도(그램), 주당 최대 음주 일수. 각 한도에는 고유한 진행 막대가 있습니다.
• 혈중알코올농도(BAC) 추정: 체중을 입력하면 Widmark 공식에 따른 현재 추정값을 얻을 수 있습니다.
• 상담용 보고서: 상담 및 카운슬링 예약을 위해 음주량을 정리한 두 페이지 분량의 PDF 보고서를 생성합니다.
• 데이터 이동성: 데이터를 CSV 파일로 내보내 외부 처리(예: LibreOffice Calc)에 사용하거나, 기기 간에 데이터를 옮기기 위한 JSON 백업을 만들 수 있습니다.
• 설정: "하루 시작" 시각을 맞춤 설정하여 늦은 밤의 음료가 전날 저녁에 집계되도록 하고, 예를 들어 12월 31일처럼 처음부터 다시 시작하고 싶을 때 평가 시작일을 설정할 수 있습니다.

앱 안에 사용 설명서가 제공됩니다.

개인정보 보호 및 보안

앱은 사용자가 입력한 내용만 저장합니다. 네트워크 관련 코드가 전혀 없으므로 네트워크에 접근할 수 없고, 데이터가 저절로 기기를 벗어나지 않습니다. 데이터는 앱의 비공개 저장소에 보관되며, 저장 시 iOS Data Protection(하드웨어 기반 파일 암호화)과 앱 샌드박스로 보호됩니다. 선택적 Face ID 또는 Touch ID 잠금은 무단 물리적 접근으로부터 보호합니다. 추적도, 사용 분석도, 클라우드 동기화도 없습니다.

호환성

이 앱은 iOS 17 이상에서 작동하며, Android 11(API 30) 이상에서도 사용할 수 있습니다.
